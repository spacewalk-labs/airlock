# 로그인 세션 이어받기 (browser-session)

로그인해야 보이는 페이지는 세션이 있어야 읽힙니다. 흔한 방법은 **사람이 브라우저에서 쿠키를 꺼내
에이전트에게 붙여넣는 것**인데, 이건 하지 않습니다.

> 🔴 **쿠키는 받지 않습니다.** 세션 쿠키는 비밀번호와 2FA를 다 통과한 뒤에 나온 **자격증명 그 자체**입니다.
> 채팅에 붙여넣는 순간 대화 기록·`ps` 명령행·셸 히스토리에 **평문으로 박히고**, 나중에 지워도 이미
> 여러 곳에 복사돼 있습니다. 사용자가 "쿠키 줄까?"라고 해도 **받지 말고** 아래 방법을 제안하세요.
> (애초에 진짜 세션 쿠키는 대개 `httpOnly` 라 브라우저 밖으로 온전히 나오지도 않습니다.)

**대신 사람은 로그인만 하고, 세션은 브라우저 안에 그대로 둡니다.** 에이전트는 그 브라우저에
**CDP(원격 디버깅 포트)** 로 붙어, 이미 로그인된 상태로 페이지를 읽습니다.

## 언제

[`crawling-scraping`](../crawling-scraping/SKILL.md) 결정 트리를 타다 **로그인 벽**을 만났을 때만. 로그인 없이 되는 페이지면 그쪽에서 끝냅니다.

```
내 노트북 ──Tailscale──▶ 홈서버 브라우저 화면 (사람이 로그인 · 세션은 이 프로필 안에만)
에이전트  ──CDP 127.0.0.1:9222──▶ 같은 브라우저 (로그인된 상태 그대로 읽기)
```

## 절차

1. **전제 확인 — Docker.** 이 절차는 Docker 로 브라우저를 띄웁니다.
   ```bash
   command -v docker || echo "Docker 없음"
   ```
   맥은 **OrbStack 실행 여부**를, 우분투는 **Docker 설치**를 먼저 확인합니다 (Airlock 기본 설치
   패키지에 Docker 는 없습니다). 설치 절차 자체는 이 스킬 범위 밖입니다.
2. **홈서버에 화면 있는 브라우저를 띄웁니다.** 포트는 **둘 다 루프백에만** 묶습니다
   (`3010` = 사람이 볼 화면, `9222` = CDP).
   ```bash
   mkdir -p ~/browser-profile
   docker run -d --name mybrowser \
     -p 127.0.0.1:3010:3000 \
     -p 127.0.0.1:9222:9222 \
     -v ~/browser-profile:/config \
     -e CHROME_CLI="--remote-debugging-port=9222 --remote-debugging-address=0.0.0.0" \
     lscr.io/linuxserver/chromium:latest
   ```
   ⚠️ `latest` 는 포트·환경변수 같은 인터페이스가 예고 없이 바뀝니다. 되도록 **고정 버전 태그**로.
3. **화면을 테일넷 안에서만 엽니다.** 🔴 **이미 쓰는 포트에 걸면 기존 Serve 설정을 덮어씁니다** —
   Airlock 이 `8443`(DevTerm)·`8444`(code-server)·`8446`(Orca)·`8447`(Paseo) 을 씁니다.
   ```bash
   tailscale serve status      # 쓰는 중인 포트 확인 → 여기 없는 번호를 고릅니다 (예 8480)
   sudo tailscale serve --bg --https=8480 http://127.0.0.1:3010
   tailscale serve status      # 나온 주소를 사람에게 그대로 전달
   ```
4. **로그인할 페이지를 미리 띄워 두고** 주소를 건넵니다 — "여기 열어서 로그인해 주세요".
   사람이 헤매지 않게 하는 것이 이 단계의 목적입니다.
5. **기다립니다.** 🔴 로그인하는 동안 **화면을 캡처하지 않습니다** — 비밀번호·2FA 코드가 기록에 남습니다.
6. **세션 확인 후 읽기.**
   ```bash
   curl -s http://127.0.0.1:9222/json/version    # CDP 가 살아 있나
   ```
   ```python
   from playwright.sync_api import sync_playwright
   with sync_playwright() as p:
       page = p.chromium.connect_over_cdp("http://127.0.0.1:9222").contexts[0].new_page()
       page.goto("<로그인해야 보이는 URL>")
       print(page.url, page.inner_text("body")[:500])
   ```
   ⚠️ **200이 곧 로그인 성공은 아닙니다.** 로그인 벽은 4xx가 아니라 **로그인 페이지로 리다이렉트**로
   막습니다. **착지한 URL과 그 화면에만 있는 문자열**로 판정하세요.
7. **다 쓰면 닫습니다.**
   ```bash
   sudo tailscale serve --https=8480 off   # 3번에서 고른 그 포트 (남기면 화면이 계속 열려 있습니다)
   docker stop mybrowser        # 프로필은 남아, 다음엔 로그인 없이 재사용
   ```

## 디버깅 포트 = 브라우저 전권

🔴 **`9222`에는 비밀번호가 없습니다.** 붙기만 하면 그 브라우저로 **읽기·클릭·글쓰기와 로그인된 모든
서비스 접근**이 됩니다. 그래서:

- **루프백(`127.0.0.1`)에만 바인딩**하고 테일넷 안에서만 씁니다. `0.0.0.0` 노출, 공개 도메인·터널
  연결은 **금지**. 확인: `ss -lntp | grep 9222` → `127.0.0.1:9222` 여야 합니다.
- **읽기 전용은 기술적으로 강제할 수 없습니다.** "읽기만 하겠다"는 규칙일 뿐 잠금장치가 아닙니다.
  그러니 **그 사이트 전용 계정**을 권하세요. 개인 구글 계정으로 SSO 로그인하면 메일·드라이브까지
  같은 세션에 들어옵니다.

## 함정

- 탭을 **전부** 닫으면 브라우저가 종료됩니다. 하나는 남기세요.
- 재시작하면 **탭은 사라져도 로그인은 남습니다**(프로필 볼륨). 다시 로그인시키기 전에 6번으로 확인.
- 계정 비밀번호가 필요하면 [`secret-manage`](../secret-manage/SKILL.md) — 값은 채팅에 올리지 않습니다.

## 출력

```
세션: <사이트> 로그인 확인 (근거: 착지 URL · "<보이는 문자열>")
수집: N건 · 정리: serve off · 브라우저 종료
```
