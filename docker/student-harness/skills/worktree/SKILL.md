# 작업 폴더 따로 펴기 (worktree)

새 일은 **본진(`~/workspace/<레포>`)에서 시작하지 않습니다.** 본진은 파일탐색기·에이전트 세션·
터미널이 **동시에 보고 있는 한 자리**라, 거기서 브랜치를 갈아타면 **다른 창에 열어 둔 파일까지
통째로 바뀝니다.** 작업마다 폴더를 따로 펴면 이 사고가 아예 없습니다.

원칙: **일 하나 = 워크트리 하나 = PR 하나.** 본진은 항상 기본 브랜치로 두고 읽기 전용처럼 씁니다.

## 언제

- 새 기능·수정·문서 작업을 시작할 때
- 한 레포에서 두 가지 일을 동시에 굴릴 때(에이전트를 여러 개 돌리는 경우 포함)
- 읽기만 할 거면 필요 없습니다 — 본진에서 그냥 읽으세요.

## 만들기

```bash
cd ~/workspace/<레포>
git fetch origin
git worktree add --no-track ../<슬러그> -b <슬러그> origin/<기본브랜치>
cd ../<슬러그>
```

- **기준은 항상 `origin/<기본브랜치>`** 입니다. 로컬 브랜치는 며칠 지나면 낡아 있어서, 그 위에
  뜨면 남이 이미 고친 것을 되돌리는 PR 이 됩니다. `git fetch` 를 먼저 하는 이유입니다.
- 🔴 **`--no-track` 을 빠뜨리지 마세요.** 없으면 새 브랜치가 `origin/<기본브랜치>` 를 따라가게
  묶여, 나중에 `git push` 가 **`git push origin HEAD:<기본브랜치>`**(= 기본 브랜치에 직접 push)
  를 첫 번째로 제안합니다. 붙이면 `git push --set-upstream origin <슬러그>` 를 제안합니다.
- 기본 브랜치 이름은 레포마다 다릅니다: `git remote show origin | grep 'HEAD branch'`.
- `<슬러그>` = 소문자·하이픈(`login-fix`, `readme-정리` ❌ → `readme-fix`). 폴더 이름과 브랜치
  이름을 같게 두면 나중에 무엇이 무엇인지 헷갈리지 않습니다.
- `../<슬러그>` 는 `~/workspace/` 바로 아래에 생깁니다 — **레포 이름과 겹치지 않게** 지으세요.

**손으로 치는 대신 스크립트로도 됩니다** — `~/.claude/skills/worktree/scripts/create-worktree.sh <슬러그>`
위 네 줄(fetch → 기본 브랜치 확인 → worktree add)을 한 번에 하고, **이미 있는 폴더·이미 있는 브랜치·
레포 이름과 겹치는 슬러그·fetch 실패**를 만나면 아무것도 만들지 않고 멈춥니다(남의 작업 덮어쓰기와
낡은 기준 위에 뜨는 것을 막습니다). 기준 브랜치를 직접 정하려면 `--base <브랜치>`.

Airlock 의 Paseo 를 쓴다면 새 작업을 만들 때 **New worktree** 를 고르는 것으로 위 과정이 끝납니다.

## 깃에 없는 파일은 따라오지 않습니다

`.env`·로컬 설정·내려받은 데이터처럼 **`.gitignore` 된 것은 새 폴더에 없습니다.** 모르고 그대로
개발 서버를 켜면 "키가 없다"로 실패합니다. **필요한 것만 손으로 복사하고, 무엇을 복사했는지
남깁니다.**

```bash
cp ~/workspace/<레포>/.env .env
```

- 복사한 목록은 [`worklog`](../worklog/SKILL.md)에 한 줄로 적어 둡니다. 다음에 같은 레포로 폴더를
  펼 때 무엇이 필요한지 다시 헤매지 않습니다.
- 시크릿을 새로 받아 붙여넣지 말고 본진 것을 그대로 복사하거나, 실행할 때
  `bws run -- <명령>` 으로 꺼내 씁니다([`secret-manage`](../secret-manage/SKILL.md)).

## 주의

- **오래 끌지 않습니다.** 기준에서 멀어지면 `git rebase origin/<기본브랜치>` 하거나 새로 시작합니다.
- **파일만 격리됩니다.** 포트·DB·캐시는 그대로 공유합니다. 두 폴더에서 개발 서버를 동시에 켜면
  포트를 다르게 잡으세요.
- **내가 만들지 않은 워크트리·브랜치·커밋 안 한 변경은 건드리지 않습니다.** 다른 세션이 쓰던
  폴더를 `git worktree remove` 로 지우면 그 안의 커밋 안 된 작업은 **되돌릴 수 없습니다.**

## 끝나면

[`ship`](../ship/SKILL.md) 으로 커밋 → PR → 머지 → **워크트리 회수**까지 한 번에 끝냅니다.
회수를 놓친 폴더는 다음 세션에서 [`session-resume`](../session-resume/SKILL.md) 이 목록으로 다시
보여 줍니다.
