# 지시 전에 회의부터 (task-discussion)

사람에게 큰 일을 맡길 때 회의로 범위와 "다 됐다"의 기준을 맞추듯, 에이전트에게도 그걸 먼저 합니다.
목표는 "한 방에 좋은 결과"가 아니라 **처음부터 어긋날 여지를 줄이는 것**입니다.
[`task-doc`](../task-doc/SKILL.md)의 **앞단** — 무엇을 쓸지 정하는 단계입니다.

## 언제

- 요청이 크거나 애매할 때, 성공조건이 사람마다 다르게 읽힐 때
- "내가 생각한 것과 다르게 나왔다"가 반복될 때
- (범위·성공조건이 이미 분명한 작은 일은 이 절차 없이 그냥 합니다.)

## 1. 크기 판정부터 (근거를 한 줄로 밝힘)

| 크기 | 신호 | 다음 |
|---|---|---|
| **작음** | 파일 1~2개 · 되돌리기 쉬움 · 몇 시간 | 회의 없이 **바로 실행** (2번 점검만 거침) |
| **중간** | 여러 파일 · 확인해 봐야 답이 갈림 · 성공조건 여럿 | 2~3번 → [`task-doc`](../task-doc/SKILL.md) |
| **큼** | 오래 걸림 · 구조 변경 · 되돌리기 어려움 | 2~3번 + 조사 위임 → [`task-doc`](../task-doc/SKILL.md) |

애매하면 한 단계 위로 봅니다. 사용자가 크기를 말했으면 그걸 따릅니다.

## 2. 빈 칸 찾기 — 두 종류를 가른다

요청을 **목표 · 범위(할 것/안 할 것) · 성공조건 · 건드리면 안 되는 것** 네 칸에 넣어 보고,
비었거나 서로 모순인 곳을 찾습니다. 판정 질문 하나:
**같은 설명을 받은 두 사람이 전혀 다른 결과를 내놓고 둘 다 "했다"고 우길 수 있는가?**
그렇다면 빈 칸입니다.

| 종류 | 무엇 | 어떻게 |
|---|---|---|
| **사실 공백** | 코드·설정·문서·웹을 **보면 답이 나오는 것** | **묻지 않습니다.** 직접 확인하거나 조사 서브에이전트에 맡깁니다 |
| **결정 공백** | 의도·우선순위·제외 범위·기한처럼 **사용자만 답할 수 있는 것** | **지금 묻습니다.** 답을 기다리는 동안 사실 조사는 돌립니다 |

## 3. 질문 규율

- **질문마다 두 가지를 붙입니다** — ① 왜 직접 확인으로는 못 푸는지 ② 답에 따라 무엇이 달라지는지.
  둘 다 못 쓰면 질문이 아닙니다. ①이 안 되면 조사로 돌리고, ②가 안 되면 버립니다.
- **묻는 것보다 싼 길이 먼저입니다.** 되돌리기 쉽고 결과를 크게 바꾸지 않으면
  **"A라고 가정하고 진행합니다(근거 · 틀렸을 때 영향)"** 라고 밝히고 갑니다. 아니면 그때 끊으면 됩니다.
- **열린 질문 금지.** "어떻게 할까요?" 대신 **추천안 + 대안 + 각각의 대가**를 함께 냅니다.
  단 **취향·우선순위처럼 사용자의 선호가 곧 정답인 것**은 추천을 달지 말고 선택지만 나란히 놓습니다
  (추천이 답을 끌어당깁니다).
- **한 번에 5개까지.** 넘으면 영향 큰 것부터 묻고, 못 물은 것은 버리지 말고 대기로 남깁니다.
- **질문 0개가 정상 경로입니다.** 개수를 채우지 마세요. 네 칸이 다 찼으면 묻지 않고 갑니다.
- 답이 안 오면: 가역·저위험인 것만 가정하고, 중요한 것은 **미결로 표시**한 채 나머지를 진행합니다.

## 4. 회의를 닫고 넘기기

- **작음** → 맞춰진 이해를 3~5줄로 되짚고 바로 실행합니다.
- **중간·큼** → [`task-doc`](../task-doc/SKILL.md)으로 넘깁니다. 회의에서 정해진 목표·범위·접근·
  성공조건·남은 미결을 그대로 문서 칸에 옮깁니다.
- 조사·구현을 나눠 맡길 곳은 [`subagent`](../subagent/SKILL.md), 결론을 선언하기 전 검증은
  [`self-verify`](../self-verify/SKILL.md).
- **미결은 지우지 말고 남깁니다.** 항목마다 **무엇이 정해지면 풀리는지**를 함께 적어 두세요.

## 출력

```
크기: 중간 (여러 파일 · 성공조건 2개) — 근거: …
직접 확인함: …
물어볼 것: 1) … / 없으면 "없음"
→ 다음: task-doc 작성 / 바로 실행
```
