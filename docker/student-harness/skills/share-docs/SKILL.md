# 문서 공유 (share-docs)

정리한 문서·교재를 **하나의 링크**로 전달할 때 씁니다. 링크는 두 종류이고 **순서가 정해져 있습니다** —
먼저 **테일넷 안에서만 보이는 내부 링크**(기본), 사용자가 명시적으로 요청할 때만 **[도메인 준비]에서
연결한 내 도메인의 공개 링크**. 둘 다 Airlock 의 **`publish`(퍼블리시 매니저)** 가 담당합니다.

> **먼저: HTML이 맞나?** 단순 텍스트 문서면 그냥 Markdown이 낫습니다. **다이어그램·원본
> 이미지·입력 폼**처럼 HTML이라야 잘 전달되는 문서에만 씁니다.
>
> 🔴 **자격증명·개인정보·재무처럼 남이 보면 안 되는 문서는 애초에 공개 발행하지 않습니다.** 공개
> 발행은 "누구나 볼 수 있게" 하는 일입니다. 그런 문서는 내부 링크까지만 쓰세요.

## 지킬 것 넷 — 나머지 형식은 자유입니다

1. `<main class="doc">` 안에 쓰고 `doc.css` 와 `doc.js` 를 각각 **한 번씩** 부릅니다.
   **이 두 줄이 문서 폭·우하단 메모지·목차·테마를 통째로 줍니다** — 빠지면 기능이 하나씩이
   아니라 한꺼번에 죽습니다.
2. 답을 받아야 하면 `.commit-bar[data-decisions]` 를 답니다. 독자가 고른 답이 마크다운으로
   복사됩니다 — 물어만 보고 회신 경로가 없는 문서는 미완성입니다.
3. 퀴즈는 `.doc-quiz` 마크업만 씁니다. 셔플·채점·해설은 `doc.js` 가 합니다.
4. 시크릿·자격증명·개인정보가 든 문서는 **공개하지 않습니다.** 공개 링크는 아는 누구나 엽니다 —
   그런 자료는 내부 링크까지만 씁니다.

클래스명과 계약은 [components.md](references/components.md), 문서 쓰는 법 상세는
[authoring.md](references/authoring.md).

## 어떻게 쓰나 — 작성 규범

- **독자는 사람입니다.** 정확성은 최저 조건이지 목표가 아닙니다 — 다 맞는데 안 읽히면 실패입니다.
- **결론과 그림이 먼저.** 첫 화면에서 "그래서 무엇"이 보이게 두고, 설명은 그다음에 붙입니다.
- **답을 받아야 하는 문서에는 회신 경로를 넣습니다.** 결정·의견을 묻는데 돌려줄 수단이 없으면 미완성입니다.
- **읽는 사람이 이해 못 할 것 같으면 다시 씁니다.** 용어는 처음 나오는 자리에서 한 번 풀어 줍니다.

## 템플릿·스타일 — 빈 파일에서 시작하지 않습니다

골격과 공용 스타일이 이 스킬에 함께 들어 있습니다. 흰 화면부터 쓰지 마세요.

- `~/.claude/skills/share-docs/templates/` — `base.html`(기본 뼈대) +
  `snippets/`(`decision`=회신 폼 · `quiz`=퀴즈). **새 문서는 이 둘로 시작합니다.**
  옛 4종(`report`·`decision`·`runbook`·`catalog`)도 남아 있지만 옛 판입니다.
- `~/.claude/skills/share-docs/assets/` — `doc.css` · `doc.js`(목차·테마·복사 버튼·퀴즈·결정폼) ·
  `doc-print.css`(인쇄용, 선택)
- `~/.claude/skills/share-docs/scripts/` — `doc-contract-lint.py`(발행 전 계약 검사) ·
  `css-collision-lint.py`(공유 클래스명 충돌)
- `~/.claude/skills/share-docs/references/` — [authoring.md](references/authoring.md)(쓰는 법) ·
  [components.md](references/components.md)(클래스·토큰 계약)

**CSS 붙이는 법.** 작업 중에는 `doc.css`·`doc.js` 를 문서 폴더에 나란히 두고 상대 경로로 걸었다가
(`<link rel="stylesheet" href="doc.css">`), **발행 직전에 문서 안으로 인라인**합니다(방법 =
`templates/README.md`). 발행 앱이 대신 넣어 주기도 하지만 **빠져도 발행은 성공**합니다(스타일만 죽습니다).

**발행 전 계약 검사.** 플레이스홀더 잔여·`<title>`/og 누락·끊긴 이미지·안 닫힌 태그를 한 번에 봅니다.
**인라인하기 전 원본에서** 돌리세요(ERROR 0 이어야 발행).

```bash
python3 ~/.claude/skills/share-docs/scripts/doc-contract-lint.py mydoc.html   # ERROR 0
python3 ~/.claude/skills/share-docs/scripts/css-collision-lint.py mydoc.html  # 클래스명 충돌
```

린트 다음에 **눈으로** 봅니다 — 콘솔 오류 0 · 이미지 로드 · 폼·퀴즈 동작 · 시크릿 없음.

## 전제 (한 번만)

- **Airlock 설치 완료** — `publish` 앱이 떠 있어야 합니다. 내부 링크는 이것만 있으면 됩니다.
- **도메인 준비 완료** — **공개할 때만**(Cloudflare Tunnel + 게이트웨이). 아직이면 먼저
  [도메인 준비] 챕터를 따르세요. 공개 링크는 그 도메인 아래로 나옵니다.

## 순서

1. **자기완결 HTML 준비** — 외부 자산(CDN·원격 이미지·폰트) 없이 단일 파일(이미지 base64, CSS/JS 인라인).
2. **내부 링크로 먼저 보여 줍니다** — 다음 절. **여기까지가 기본값**입니다.
3. **공개는 사용자가 "공개해 줘"라고 말했을 때만** — 아래 "공개 범위" 절. **같은 이름으로 재발행 = 같은 링크 유지 + 내용만 갱신.**

## 내부 링크 먼저 — 테일넷 안에서만 보기 (기본값)

Airlock 은 **공유 폴더**(`share_dir`, 기본 `/opt/airlock/share`)의 파일을 `/publish/files/` 아래로
서빙합니다. 이 경로는 hub 게이트 뒤라 **내 신원(과 등록한 협업자)만** 열립니다. 공개와 달리 되돌릴
것도 만료도 없으니, **문서를 만들면 이 링크부터 사람에게 줍니다.**

**① 공유 폴더에 걸기** — 심링크(원본 유지)나 복사. 발행 앱에는 파일을 넣는 기능이 없습니다.
🔴 **인라인본을 거세요.** `/publish/files/` 는 공유 폴더를 그대로 붙이는 자리라
(`alias /opt/airlock/share/;` — 대체 경로 없음), 문서 하나만 걸면 `doc.css`·`doc.js` 요청이 **404** 납니다 —
**문서는 열리는데 스타일만 조용히 죽습니다.**

```bash
SHARE=/opt/airlock/share                             # airlock.toml 의 [apps.publish] share_dir
ln -sfn "$PWD/mydoc.pub.html" "$SHARE/mydoc.html"    # 인라인본 (templates/README.md)
```

> 인라인본이 없다면 **`doc.css`·`doc.js` 도 같은 공유 폴더에 함께** 걸어야 스타일이 삽니다.
> 파일명은 **영문·숫자·하이픈**으로 지으세요. slug 는 파일명에서 영문·숫자만 남겨 만들고,
> 그게 4자 미만이면 `<title>` 에서, 그것도 4자 미만이면 `doc-3f9a1c` 같은 뜻 없는 주소가 됩니다.

> 🔴 **nginx 워커(`www-data`)가 심링크를 따라 원본까지 갑니다 — 원본 경로가 막히면 안 열립니다.**
> 원본 파일은 `644`, **거기까지의 모든 상위 폴더에 `o+x`** 가 있어야 합니다.
> - `chmod o+x ~`(우분투 24.04 기본 `0750` → `0751`) 는 **누구에게나 `--x`** 를 줍니다 — 지나가기만
>   되고 목록은 못 봅니다. 대안인 **`0750` + 그룹 `www-data`** 는 대상이 nginx 하나로 좁아지는 대신
>   그 하나에게 **`r-x`(지나가기 + 목록 열거)** 를 줍니다. 좁은 대상 vs 좁은 권한이라 취향껏 고르세요.
>   단 **Airlock 설치 검사는 `o+x` 를 요구**해 `0750` 폴더는 거부합니다(거부 메시지가 언급만 할 뿐입니다).
> - **공유 폴더는 설치가 보장해 주지 않습니다.** 설치는 **이번에 새로 만든 폴더만** `755` 로 맞추고,
>   이미 있던 `share_dir` 은 그대로 둡니다. 설치 시점 `o+x` 검사도 `share_dir` 은 **아예 보지 않아서**,
>   문제는 ③의 **런타임 403** 으로만 드러납니다.

**② 내 주소 확인** — 머신·테일넷 이름은 사람마다 다릅니다. 묻지 말고 직접 읽으세요.

```bash
tailscale status --json | python3 -c 'import sys,json;print(json.load(sys.stdin)["Self"]["DNSName"].rstrip("."))'
```

**발행 매니저는 `https://<내-머신>.<내-테일넷>.ts.net/publish/`** 입니다 — 아래 절에 나오는
`🌐 Publish externally`·`Access`·`Revoke`·`Change expiry` 버튼이 전부 이 화면에 있습니다.

**③ 200 을 실측하고 나서 링크를 줍니다.** 안 열리는 링크를 주는 게 가장 흔한 실패입니다.

```bash
BASE='https://<내-머신>.<내-테일넷>.ts.net'     # ②에서 확인한 값으로 바꿔 넣습니다
curl -s -o /dev/null -w '%{http_code}\n' "$BASE/publish/files/mydoc.html"   # 200
```

- **`404` = 공유 폴더에 그 이름이 없습니다.** ①을 안 했거나 이름이 다릅니다. 심링크는 있는데
  **원본을 옮겼거나 지운(깨진 심링크)** 경우도 404 입니다. 목록 `$BASE/publish/files/` 에서 확인.
- **`403` = 권한입니다. 파일·폴더부터 봅니다.** 위 🔴 대로 원본까지 가는 길이 nginx 에게 막혔다는
  뜻입니다. `namei -l "$SHARE/mydoc.html"` 로 한 칸씩 훑어 `o+x` 없는 폴더를 찾으세요.
  🔴 **이때 화면에는 "This isn't your Airlock / You're signed in, but you're not the owner of
  this box." 가 뜹니다** — 신원 문제처럼 보이지만 대개 원인은 권한입니다. 이 화면에 속아 신원부터
  뒤지지 마세요. 경로가 전부 멀쩡한데도 403 이면 **그때** hub 게이트 신원 — Airlock 설정의
  owner 가 내 Tailscale 로그인 **이메일**과 같은지 봅니다.

## 이미지 — 인라인 base64 는 작은 것만

증거는 문장보다 이미지가 빠릅니다. 다만 **넣는 방법이 두 가지**이고, 잘못 고르면 조용히 깨집니다.

- **작은 아이콘·도식(수십 KB)** — 인라인 base64 나 인라인 SVG. 파일 하나로 끝나 메일·USB 로 보내도 열립니다.
- **큰 증거 이미지(스크린샷·그래프·도면)** — **절대 손으로 base64 로 박지 마세요.** base64 는 원본보다
  약 33% 커지고, 그 덩어리가 HTML 한 줄에 들어가 편집기·diff·리뷰가 다 무거워집니다. 대신
  **문서 옆에 실파일로 두고 상대경로로 링크**합니다.

```
mydoc.html
img/db-latency.png     ← 문서와 같은 폴더 아래
doc.css  doc.js
```

```html
<figure class="fig">
  <a href="img/db-latency.png">
    <img src="img/db-latency.png" alt="p99 응답이 08:40 에 4초로 튀는 그래프">
  </a>
  <figcaption><strong>08:40 의 급등.</strong> 배포 직후 p99 가 <code>0.3s → 4.1s</code>. 클릭하면 원본 해상도로 열립니다.</figcaption>
</figure>
```

본문에 놓는 `<img>` 는 읽기 좋은 크기로 줄여 두고, **원본 해상도는 `<a href>` 로 열리게** 합니다.
설명은 `alt` 로 끝내지 말고 `<figcaption>` 에 **무엇을 봐야 하는지**를 적습니다.

**발행 경로에 따라 동작이 다릅니다 — 이걸 알고 링크를 주세요.**

- **내부 링크(`/publish/files/`, 기본값)** — 공유 폴더를 그대로 서빙합니다. `img/` 폴더째 공유
  폴더 아래 같은 상대 구조로 걸면 `<img>` 도 `<a href>` 원본 링크도 그대로 삽니다. 여기서는
  인라인이 필요 없습니다.
- **공개 발행(스냅샷)** — 발행 앱이 스냅샷을 만들 때 **`<img src>` 의 로컬 파일만** 찾아
  base64 로 넣습니다. 즉 **큰 이미지를 그대로 두면 스냅샷 HTML 이 그만큼 부풉니다** — 본문
  `<img>` 는 미리 줄여 둡니다. 그리고 🔴 **`<a href="img/…">` 원본 링크는 인라인되지 않습니다** —
  그 파일도 공유 폴더에 함께 걸어 두지 않으면 공개본에서 클릭이 404 가 됩니다.
- 공유 폴더 **밖**을 가리키는 참조는 (의도적으로) 거부되고 **발행은 그대로 성공**합니다 —
  이미지만 빠진 채로. 그래서 발행 뒤 **공개 URL 을 직접 열어 눈으로 확인**합니다.

좌표·표 같은 구조 데이터는 이미지로 찍지 말고 `<table>` 로 다시 그립니다 — 병합·빈 칸·누락이
그때 드러납니다. 증거용 색은 토큰 밖 색을 써도 되지만 **범례를 반드시** 붙입니다.

## 주의 (중요)

- **공개는 되돌리기 어렵습니다.** 발행 전 **시크릿·내부 정보·개인정보**가 없는지 확인하세요.
- **링크(slug)를 깨뜨리지 마세요.** 이미 배포한 링크는 이름을 바꾸지 말고 **같은 이름으로 재발행**.
- **여러 문서를 서로 링크했다면 각각 발행하지 마세요** — slug 가 갈라져 링크가 다 깨집니다. 아래 절.

## 여러 문서를 서로 링크했다면 — 묶음 발행

발행 앱의 **묶음 발행**은 여러 문서를 **링크 하나** 아래로 함께 올리면서 문서 사이의 `<a href>` 를
**자동으로 고쳐 줍니다.** 각각 발행해 링크를 손으로 갈아 끼우지 마세요. **클릭으로 됩니다** — 묶을
문서를 **전부 공유 폴더에 먼저 걸어 둔 뒤**(이름은 `href` 에 적힌 그대로) 표지 문서 줄의
**`🌐 Publish externally`** 를 누르면 창에 **`Linked documents`** 목록이 뜹니다. 링크를 따라가
찾아낸 문서가 **미리 체크된 채로** 나오니, 뺄 것만 해제하고 **`Publish`**.

- 표지는 slug 루트(`…/`)로, 나머지는 **원래 파일명 그대로** 그 아래 들어갑니다.
- **체크하지 않은** 문서로 건 링크는 안 고쳐지고 **경고로만** 뜹니다 — 창의 경고 줄을 읽으세요.
- 문서는 **공유 폴더 바로 아래 평평하게** 있어야 합니다. 하위 폴더로 건 링크는 안 묶입니다.
- **`[apps.publish.public_target]` 의 `mode = "local"` 에서만** 됩니다(암호 게이트와 같습니다).
  아니면 이 패널이 아예 안 뜹니다.
- 🔴 **갱신할 때 `Refresh`·`Republish` 를 누르지 마세요.** 그 둘은 **표지 한 장만** 다시 올려
  **묶었던 나머지가 사라집니다.** 갱신은 **Revoke 뒤 묶음 발행을 다시** — 이때 링크가 새로 나가므로
  묶음은 처음부터 기간을 넉넉히 잡으세요.
- 🔴 **자식 문서를 고친 것은 화면에 안 보입니다.** `Source changed` 표시는 **표지 파일만** 보고
  뜹니다. 자식을 하나라도 고쳤으면 **반드시 묶음을 다시 발행**하세요 — 안 그러면 공개본만
  조용히 옛 내용으로 남습니다.

## 공개 범위 — 누구나 / 암호 있는 사람만

[도메인 준비] §6대로 켜 두면 `doc.내도메인.com` 은 **공개 폴더**(`share-public`)를 인증 없이
정적 서빙합니다. 즉 발행한 순간 **링크를 아는 사람은 누구나** 봅니다.

> ⚠️ 공개 폴더는 **`share_dir`가 아닙니다** — 위 내부 링크 절의 그 폴더를 공개로 서빙하면 거기
> 걸어 둔 것이 전부 샙니다. nginx `root`는 반드시 `share-public`(겹치면 Airlock 설치가 거부합니다).

**발행한 뒤 공개 URL 을 직접 열어 200 을 확인합니다.** 원본 grep 은 자산 인라인을 오진합니다.

```bash
curl -s -o /dev/null -w '%{http_code}\n' 'https://doc.내도메인.com/<slug>/'   # 200 이어야 함
```

### 기간 — 진짜로 만료됩니다

발행할 때 **24시간 / 7일 / 14일 / 30일** 중에서 고릅니다. 기간이 지나면 정리 타이머가 스냅샷을
**디스크에서 지워** 링크가 404가 됩니다(최대 1시간 이내). 즉시 내리려면 **Revoke**,
기간을 바꾸려면 **Change expiry**.

- **같은 파일을 다시 발행하면 slug(링크)는 그대로**, 내용과 기간만 갱신됩니다.
- 만료 뒤 다시 발행하면 **링크가 반드시 새로 나갑니다** — 정리 타이머가 옛 기록을 먼저 지워
  재사용할 slug 가 남아 있지 않습니다. 계속 열어 둘 문서는 만료 전에 **Change expiry** 로 늘리세요.

### 암호 게이트 — 발행 앱의 `Gated` 모드로

암호 게이트는 **발행 앱에 내장**돼 있습니다. 발행 창의 **`Access`** 를 `Gated (password)` 로
바꾸고 비밀번호를 넣으면 끝입니다.

> 🔴 **nginx `auth_basic` 과 `htpasswd` 파일을 손으로 만들지 마세요.** 그렇게 건 게이트는
> **발행 앱이 모르는 설정**이라 **만료가 없습니다** — 문서를 다 쓴 뒤에도 설정과 비밀번호 파일이
> 고아로 남고, 지우는 걸 잊으면 그대로 살아 있습니다. 내장 모드는 만료·회수와 함께 정리됩니다.

- 링크는 `https://doc.내도메인.com/g/<slug>/`. 브라우저가 묻는 **아이디는 slug 그대로**, 암호는 넣은 값.
- **문서마다 암호가 따로**입니다 — 한 문서의 암호로 다른 문서가 열리지 않습니다.
- **기간(24시간·7일·14일·30일)이 그대로 적용**되고, 만료·**Revoke** 시 스냅샷과 **비밀번호 파일까지** 지워집니다.
- 이미 공개(Open)로 나간 문서를 Gated 로 다시 발행하면 **공개본을 먼저 지웁니다** — 옛 링크가 안 남습니다.
- 같은 slug 를 Gated 로 다시 발행하면 **암호가 갱신**됩니다.
- **암호는 채팅·문서에 남기지 말고** 링크와 다른 경로로 전달하세요.

**`Access` 목록에서 `Gated` 가 회색이면** 창에 이유가 같이 뜹니다. 보통 둘 중 하나입니다.

1. `htpasswd` 가 없음 → `sudo apt install apache2-utils` 후 publish 앱 재시작:
   `systemctl --user restart airlock-publish.service` (로그: `journalctl --user -u airlock-publish`).
2. `[apps.publish.public_target]` 의 `mode` 가 `"local"` 이 아님 → 게이트는 **내 서버 nginx가 거는
   것**이라 원격 ingest 로는 안 됩니다.

**한 번만: 게이트 경로를 공개 서버 블록에 include.** 설치 스크립트가 조각 파일을 만들어 두므로,
[도메인 준비] §6.3 의 `doc-public.conf` **같은 server 블록 안**에 한 줄만 넣고 reload 합니다.

```nginx
    include /etc/airlock/nginx/public-includes.d/publish-gated.conf;
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

검증 — 암호 없이 **401**, 암호를 넣으면 **200** 이어야 합니다.

```bash
curl -s -o /dev/null -w '%{http_code}\n' 'https://doc.내도메인.com/g/<slug>/'                    # 401
curl -s -o /dev/null -w '%{http_code}\n' -u '<slug>:<암호>' 'https://doc.내도메인.com/g/<slug>/'  # 200
```

> 암호 게이트는 **"링크만으로는 못 본다"** 까지입니다. 암호를 아는 사람은 전부 같은 익명 방문자이고
> 누가 열었는지 기록도 없습니다 — **"이 사람만 본다"는 보장이 아닙니다.** 그런 보장이 필요하면 발행하지 마세요.

