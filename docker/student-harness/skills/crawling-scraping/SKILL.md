# 크롤링 · 스크래핑 (crawling-scraping)

웹에서 데이터를 모을 때, **가장 싸고 안 깨지는 층에서 멈추는 것**이 핵심입니다. 무거운 브라우저
자동화로 바로 가지 말고, 아래 순서로 **위에서부터** 시도하세요.

> ⚠️ **먼저 확인:** 대상 사이트의 **이용약관·robots.txt·저작권·개인정보** 준수 여부는 **사용자 책임**입니다.
> 허용되지 않는 수집은 하지 않습니다. 이 스킬은 '어떻게'만 다룹니다.

## 결정 트리 (위에서부터)

1. **공식 API** 가 있나? → 있으면 그걸 쓴다(가장 안정적).
2. **숨은 API** — 브라우저 개발자도구 **Network 탭**에서 페이지가 부르는 JSON 요청을 찾는다. 있으면 그걸 직접 호출.
3. **정적 HTML** — 내용이 그냥 HTML에 있으면 `requests` + `BeautifulSoup`(파이썬)로 충분.
4. **브라우저 자동화** — JS로 그려지는 페이지만 `playwright`로. 느리고 무거우니 **최후에서 두 번째**.
5. **분산·대규모** — 정말 클 때만. 대부분은 여기까지 갈 일 없습니다.

> **한 도구로 층 갈아타기 — Scrapling(무료·OSS).** `pip install "scrapling[fetchers]"`. 정적(`Fetcher`)→JS(`DynamicFetcher`)→
> 안티봇(`StealthyFetcher`)을 **fetcher만 바꿔** 위 결정 트리 그대로 오르내립니다. 셀렉터 자가복구(`find_similar`)로
> 사이트가 바뀌어도 덜 깨집니다. (엔터프라이즈급 안티봇까지는 보장 안 됨 — 그땐 상용 서비스.)

## 로그인해야 보이는 사이트 (위 트리와 별개 축)

로그인 벽은 "더 센 도구"로 뚫는 문제가 아니라 **세션을 어떻게 얻느냐**의 문제입니다.
→ [`browser-session`](../browser-session/SKILL.md): 사람이 **직접 브라우저에서 로그인**하고,
그 세션을 에이전트가 이어받습니다. 값이 오가지 않고, 평소 쓰던 IP·브라우저에서 세션이 태어나
재인증·계정 정지 위험도 낮습니다.

> 🔴 **사용자에게 쿠키를 붙여넣게 하지 않습니다.** 세션 쿠키는 2FA까지 우회하는 **자격증명**입니다.
> 붙여넣는 순간 채팅 기록·`ps` 명령행·셸 히스토리에 **평문으로** 남습니다
> ([`secret-manage`](../secret-manage/SKILL.md)의 "값을 채팅에 붙여넣지 않는다"와 같은 규칙).
> **사용자가 "쿠키 줄까?" 해도 받지 않습니다.**

## 예의 (차단당하지 않기)

- **`robots.txt` 확인**, 요청 사이에 **딜레이**, **동시성 낮게**, 정직한 **User-Agent**.
- **429/403이 뜨면 물러서기**(지수 backoff) — 세게 두드리지 않습니다.
- 같은 자료를 반복 받지 않게 **캐시/조건부 요청**.

## 막혔는지는 상태 코드로만 보면 절반을 놓칩니다

**200을 받고도 막힌 것일 수 있습니다.** 안티봇 챌린지 페이지("잠시만 기다려 주세요")나
JS가 아직 안 그린 **빈 껍데기 HTML**도 똑같이 200으로 옵니다. 코드만 보고 통과시키면
빈 데이터가 조용히 하류로 흘러갑니다.

**판정은 파싱 결과로 합니다** — 기대한 **핵심 필드가 실제로 들어 있나?**

- 없으면 → 막힘 또는 미렌더로 보고, 멈추거나 한 층 위(브라우저)로 올립니다. 빈 값을 저장하지 않습니다.
- **0건은 성공이 아니라 실패**로 취급해 예외를 냅니다. 사이트 개편은 대개 이렇게 조용히 옵니다.
- 본문에 `Cloudflare`·`잠시만`·`Just a moment`·`Access Denied` 같은 문구가 있으면 챌린지로 봅니다.

## 견고성

- 선택자(selector)는 **여러 후보(fallback)** 로. 사이트가 바뀌면 잘 깨지니, **실패를 조용히 넘기지 말고 로깅**.
- 받은 데이터는 **검증**(빈 값·형식) 후 저장.

## 유튜브 영상 → 전사본 (스크립트 있음)

유튜브는 **직접 긁지 마세요.** 이 스킬에 딸린 스크립트를 쓰면 **메타(제목·채널·길이·챕터)와 자막**을
마크다운 한 파일로 뽑아 줍니다.

```bash
python3 ~/.claude/skills/crawling-scraping/scripts/yt-transcript.py <유튜브URL> -o transcript.md
```

- 전제: **`yt-dlp`** 가 필요합니다 (`pip install -U yt-dlp` 또는 `pipx install yt-dlp`).
- 자막은 **사람 자막 > 자동 자막** 순으로 고릅니다. 언어를 안 주면 **영상 원어**를 씁니다
  (한국어 영상에 `-l en` 을 주면 기계번역이 와서 오류가 한 겹 더 얹힙니다).
- 🔴 `yt-dlp` 를 직접 부를 때 **자막 언어에 와일드카드(`--sub-langs "*"`)를 쓰지 마세요** — 언어 수만큼
  요청이 나가 **429(차단)** 를 부릅니다. 필요한 언어만 지정합니다.
- `--meta-json m.json` 을 주면 메타를 JSON 으로도 남깁니다. **자막 유무는 그 파일의 `subs` 로 판정**하세요 —
  자막이 없어도 문서는 만들어지고 종료 코드는 0 입니다.
- 30초 단위 문단으로 묶어 주므로 **타임스탬프를 그대로 인용**할 수 있습니다(`&t=162s`).

## 시크릿

- 프록시·API 키가 필요하면 **평문 금지** → [`secret-manage`](../secret-manage/SKILL.md)로 금고(`bws`)에 넣고
  `bws run` 으로 주입.

## 출력

```
방법: (API / 숨은 API / 정적 / 브라우저 / 로그인 세션) 중 택 — 이유
수집: N건, 실패 M건(로그: <경로>)
판정: 핵심 필드 확인 ✔ (0건이면 실패로 처리)
```
