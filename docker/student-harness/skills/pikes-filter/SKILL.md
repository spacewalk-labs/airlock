# 파이크 필터 (pikes-filter)

"단순하게 짜라"는 말은 판정이 안 됩니다. Rob Pike의 5원칙은 **무엇을 보고 복잡하다고 할지**를 정해 줍니다.
[`code-review`](../code-review/SKILL.md)의 **단순성** 항목을 볼 때 이 스킬을 불러 기준을 갖추세요.

## 언제

- 함수가 길고 조건문이 많아 손대기 무서울 때
- 리뷰에서 "복잡한 것 같다"가 나왔는데 근거를 못 댈 때
- 성능 때문에 넣었다는 코드가 실제로 필요한지 의심될 때

## 5원칙 — 판정 가능한 신호로

| 원칙 | 코드에서 찾을 신호 |
|---|---|
| **1. 추측성 최적화 금지** | 캐시·메모이제이션·조기 종료가 있는데 **왜 넣었는지 측정 기록이 없다** |
| **2. 측정 전 튜닝 금지** | "여기가 느릴 것 같아서"라는 주석·커밋 메시지. 실제 프로파일 결과는 없다 |
| **3. N이 작으면 정교한 알고리즘 불필요** | 원소가 수십~수백인데 색인·트리·이진탐색·직접 만든 캐시가 있다 |
| **4. 자료구조가 로직보다 중요** | **중첩 분기가 3단 이상**이거나, 길이가 같은 리스트 여러 개를 인덱스로 짝지어 쓴다 |
| **5. 데이터 중심 설계** | 값→값 매핑을 `if/elif` 사슬·`switch`로 쓴다. 불리언 플래그 3개 조합으로 상태를 표현한다 |

> 4·5번이 핵심입니다. **분기가 깊다는 건 문제가 어렵다는 뜻이 아니라, 자료구조가 그 일에 안 맞는다는
> 신호**입니다. 데이터를 바로잡으면 분기는 대부분 사라집니다.

## 진단 절차

1. 대상 코드를 읽고 **5원칙마다 위반/아님**을 판정합니다. 위반이면 **줄 번호 + 한 줄 근거**를 답니다.
2. 가장 심한 곳 하나를 골라 **왜 복잡한지 → 어떻게 단순해지는지**를 씁니다.
3. **고친 코드를 제시**합니다. 분기를 데이터로 옮기는 방향으로.
4. **동작이 같은지 테스트로 확인**합니다. 이건 리팩터링이지 기능 변경이 아닙니다.

## 자주 쓰는 치환

**if 사슬 → 룩업 테이블** (5번)

```python
# before
if code == "A": label = "우수"
elif code == "B": label = "보통"
elif code == "C": label = "미흡"
# after
LABELS = {"A": "우수", "B": "보통", "C": "미흡"}
label = LABELS.get(code, "미정")
```

**병렬 리스트 → 레코드 하나** (4번). 길이가 어긋나도 조용히 굴러가는 구조를 없앱니다.

```python
# before: names[i], scores[i], passed[i] 를 인덱스로 맞춰 씀
# after
from dataclasses import dataclass

@dataclass(frozen=True)
class Row:
    name: str
    score: int
    passed: bool

rows = [Row(n, s, p) for n, s, p in zip(names, scores, passed)]
```

**구간 분기 → 규칙 표** (4번)

```python
RULES = (("소형", 0, 100), ("중형", 100, 1000), ("대형", 1000, float("inf")))
size = next(name for name, lo, hi in RULES if lo <= v < hi)
```

## 주의

- **단순화가 늘 정답은 아닙니다.** N이 실제로 크면 알고리즘이 필요합니다 — 그때는 **측정값을 근거로
  코드나 주석에 남기세요.** 근거가 붙으면 1·2번 위반이 아닙니다.
- **최적화를 지우는 것도 측정 없이 하면 똑같은 추측**입니다. 지운 뒤 느려지지 않았는지 확인하세요.
- 취향 논쟁으로 가지 않습니다. 판정은 위 표의 **신호가 실제로 코드에 있는지**로만 합니다.

## 출력

```
위반: 4(자료구조) · 5(룩업 누락)   | 통과: 1 · 2 · 3
가장 심한 곳: <파일>:<줄> — 중첩 4단 분기 → 규칙 표로 치환
결과: 분기 12줄 → 표 4줄, 기존 테스트 통과
```
