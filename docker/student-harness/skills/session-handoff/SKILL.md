# 이어받을 메모 남기기 (session-handoff)

대화가 길어지면 맥락을 비워야 합니다(`/clear`·`/compact`). 비우는 순간 **지금 머릿속에 있던 것은
전부 사라집니다.** 비우기 **직전에** 다음 세션이 따라올 수 있는 **포인터**를 남깁니다.

## session-close 와의 차이

| | session-handoff | [`session-close`](../session-close/SKILL.md) |
|---|---|---|
| 언제 | **일이 안 끝났는데** 대화를 끊을 때 | **일이 끝나서** 마감할 때 |
| 남기는 것 | 다음에 이을 지점·파일 위치·미해결 질문 | 한 일 요약·검증 상태·정리 |
| 워크트리 | **건드리지 않음** (계속 씁니다) | 마감 절차에서 정리 |

헷갈리면 이렇게 판단합니다: **10분 뒤 같은 일을 계속할 거면 handoff, 오늘 이 일은 여기까지면
session-close.**

## 무엇을 남기나 — 포인터 3개

이 셋이 빠지면 핸드오프가 실패합니다. 배경 설명보다 **정확한 포인터**가 훨씬 유용합니다.

1. **다음에 이을 지점** — 무엇을 하려던 참이었는지 한 줄 + 바로 칠 명령 한 줄
2. **관련 파일** — `경로:줄` 로. "그 파일" 같은 표현은 다음 세션이 못 찾습니다
3. **미해결 질문** — 결정 못 한 것, 사용자에게 물어야 할 것

## 어디에

레포 루트 **`WORKLOG.md` 의 맨 아래에 append** 합니다. 세션 시작 훅이 이 파일의 **마지막 부분을
읽어** 다음 세션에 붙여 주기 때문에, 위에 쓰면 복원되지 않습니다. 항목 제목은
`## 핸드오프 <절대날짜>` 로 시작해야 [`session-resume`](../session-resume/SKILL.md)이 찾습니다.

```markdown
## 핸드오프 2026-08-09 — 로그인 폼 검증 붙이는 중

- 다음: 빈 이메일일 때 에러 문구 띄우기 → `npm test -- login` 부터 실행
- 작업 폴더: `/home/<사용자>/workspace/myapp-login-fix` (브랜치 `login-fix`)
- 파일:
  - `src/auth/LoginForm.tsx:88` — 검증 함수 붙이는 자리(비어 있음)
  - `src/auth/validate.ts:12` — 여기 규칙을 재사용하기로 함
- 이미 해 봤는데 안 된 것: 브라우저 기본 검증만 쓰기 → 문구를 한국어로 못 바꿈
- 미해결: 에러 문구를 필드 아래에 둘지 상단에 모을지 — 사용자 확인 필요
```

## 규칙

- **절대 경로·절대 날짜.** "위 폴더"·"어제" 는 다음 세션에 아무 의미가 없습니다.
- **사실만.** 하려다 만 것은 "안 했음" 이라고 적습니다. 다음 세션이 됐다고 믿고 넘어갑니다.
- **시크릿 값 금지.** 키·토큰·비밀번호는 이름만 적습니다(`bws` 에서 꺼내 쓴다고만).
- **워크트리·브랜치를 정리하지 않습니다.** 일이 계속되므로 그대로 둡니다.
- **커밋은 사용자가 시킬 때만.** 맥락을 비운다고 자동으로 커밋·push 하지 않습니다.
  다만 작업이 사라지면 곤란할 만큼 쌓였다면 커밋을 **제안**은 합니다.

## 출력

```
📄 WORKLOG.md 에 "핸드오프 <날짜> — <제목>" 추가
➡️ 다음 세션 첫 명령: <명령 한 줄>
```

이렇게 남긴 뒤 `/clear` 또는 `/compact` 하시면 됩니다. 다음 세션은
[`session-resume`](../session-resume/SKILL.md)으로 열면 이 항목이 후보 목록에 뜹니다.
