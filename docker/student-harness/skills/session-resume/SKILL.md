# 세션 열기 (session-resume)

새 대화는 **기억이 0인 상태**로 시작합니다. 먼저 지난 자취를 훑고, **무엇을 이어갈지 사용자에게
고르게 한 뒤** 일을 시작합니다.

## 언제

- 새 세션을 열었을 때, "어디까지 했지 / 이어서 하자" 라고 할 때, 며칠 쉬었다 돌아왔을 때

## 1. 남은 핸드오프 목록 보여주기 (자동 선택 금지)

핸드오프는 레포 루트 `WORKLOG.md` **맨 아래**에 `## 핸드오프 <날짜>` 항목으로 쌓입니다
([`session-handoff`](../session-handoff/SKILL.md)). 세션 시작 훅이 이 파일의 마지막 부분을
자동으로 읽어 주지만, 여러 건이 쌓였으면 목록으로 다시 정리해 보여 줍니다.

```bash
grep -n '^## 핸드오프' WORKLOG.md | tail -5
```

🔴 **가장 최근 것을 알아서 고르지 않습니다.** 여러 작업을 번갈아 하다 보면 맨 마지막 핸드오프가
지금 이어갈 일이 아닌 경우가 흔합니다. **목록을 보여 주고 사용자가 고르게** 합니다.
고른 뒤 그 항목만 읽어 다음 지점·관련 파일·미해결 질문을 꺼냅니다.

하나도 없으면 "이어받을 핸드오프 없음 — 새로 시작합니다" 라고 알립니다.

## 2. 본진이 기본 브랜치인지 확인

```bash
cd ~/workspace/<레포>
git branch --show-current; git status --short
```

- 본진이 **기본 브랜치가 아니거나 지저분하면** 알리기만 하고 **자의로 되돌리지 않습니다.**
  다른 세션이 쓰던 중일 수 있고, `git reset`·`git checkout` 은 그 작업을 날립니다.
- 정상이면 `git pull --ff-only` 로 최신으로 맞춥니다.

## 3. 남아 있는 워크트리 훑기

```bash
git worktree list                          # 남아 있는 작업 폴더
git -C <워크트리경로> status --short       # 커밋 안 한 변경이 있는지
gh pr list --state all --head <슬러그> --json number,state --jq '.[0]'   # 머지됐는지
```

각 워크트리마다 **브랜치 이름 / 커밋 안 한 변경 유무 / 머지 여부**를 한 줄로 정리해 보여 줍니다.

🔴 **머지 판정은 PR 상태(`gh`)로 합니다 — `git branch --merged` 는 squash 머지를 못 잡습니다.**
[`ship`](../ship/SKILL.md)이 squash 로 머지해 커밋을 새로 만들기 때문에, 그 목록만 믿으면 이미
머지된 폴더를 영영 못 줍습니다.

## 4. 이미 끝난 것은 회수 제안

[`ship`](../ship/SKILL.md)으로 머지까지 갔으면 회수도 거기서 끝납니다. 여기서 줍는 것은
**지난번에 회수하지 못하고 남은 것**입니다.

- **머지됨 + 커밋 안 한 변경 없음** → "회수할까요?" 하고 **사용자 승인을 받은 뒤**
  `~/.claude/skills/session-close/scripts/retire-worktree.sh <워크트리경로>` (회수 절차의 정본 =
  [`session-close`](../session-close/SKILL.md) 4단계 — 폴더·로컬 브랜치·원격 브랜치까지 함께).
- 여기 목록은 **전부 지난 세션 것**이라 승인을 받습니다. 다른 세션이 지금 쓰고 있을 수도 있으니
  자의로 지우지 않습니다.
- **머지 안 됨 / 변경이 남음** → 그대로 두고 보고만 합니다(스크립트도 이 경우엔 아무것도 지우지
  않고 사유만 냅니다). 지우면 되돌릴 수 없습니다.

## 출력

```
📌 이어받을 후보: 1) 핸드오프 <날짜> — <제목>  2) …   (없으면 "없음")
🌳 본진: <브랜치> (깨끗함/변경 있음)
🧰 워크트리: <폴더> <브랜치> [머지됨·회수 가능 / 진행 중 / 변경 남음]
➡️ 어느 것부터 이어갈까요?
```

사용자가 고르기 전에는 파일을 고치기 시작하지 않습니다. 새 일을 시작한다면
[`worktree`](../worktree/SKILL.md)로 폴더부터 폅니다.
