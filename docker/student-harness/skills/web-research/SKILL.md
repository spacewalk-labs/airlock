# 웹 조사 (web-research)

사실을 확인하거나 여러 자료를 비교·종합할 때 씁니다. 페이지를 긁어 오는 [`crawling-scraping`](../crawling-scraping/SKILL.md)과
달리, **검색으로 소스를 찾아 읽고 정리**하는 가벼운 조사입니다.

## 언제

- 최신 정보·수치 확인, 여러 관점 비교, 낯선 주제 빠르게 파악.

## 순서

1. **질문 쪼개기** — 큰 질문을 답 가능한 작은 질문들로.
2. **검색·읽기** — 관련 소스를 찾아 핵심만 발췌.
3. **교차 확인** — 중요한 사실은 **서로 독립된 소스 2개 이상**으로 확인. 1차 소스(공식·원문)를 우선.
4. **출처와 함께 종합** — 결론 + **근거 링크**. 확실치 않은 건 "확실치 않음"이라 표시.

## 서브에이전트 활용

- 방향이 여럿이면 [`subagent`](../subagent/SKILL.md)로 **병렬 조사** 후 **결론만** 회수(원문 통째로 X).

## 주의

- **출처를 반드시 남깁니다.** 링크 없는 단정은 피합니다.
- **날짜를 확인**합니다(오래된 정보 주의). 수치는 과장하지 않습니다.
- 검색 결과가 곧 사실은 아닙니다 — 상충하면 그대로 드러냅니다.

## 출력

```
질문: …
결론: … (근거: <링크1>, <링크2>)
불확실: …
```
